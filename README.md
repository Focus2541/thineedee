# ที่นี่ดี

สมุดจดรีวิวที่พัก ร้านอาหาร และที่เที่ยว สำหรับใช้กันสองคน เช่น "ที่พักนี้ขอห้องชั้น 4 ฝั่งทะเลสาบ จะเห็นฟูจิ"

ใช้งานที่ **https://focus2541.github.io/thineedee/**

## ทำอะไรได้

- จดรีวิว 3 ประเภท: ที่พัก ร้านอาหาร ที่เที่ยว
- **จุดที่ต้องจำ** แตะป้ายสำเร็จรูปแล้วพิมพ์สั้น ๆ เช่น เห็นวิวจากห้อง, ห้องที่ควรขอ, เวลาที่ควรไป, เมนูเด็ด, มุมถ่ายรูป, ข้อเสีย
- ให้ดาว และคะแนนแยกหมวดตามประเภท (ไม่บังคับ)
- ใส่รูปได้สูงสุด 8 รูปต่อรีวิว แอปย่อรูปในมือถือก่อนอัปโหลด ประหยัดเน็ตและพื้นที่ Drive
- เก็บตำแหน่งปัจจุบัน หรือวางลิงก์ Google Maps แล้วกดเปิดแผนที่ได้
- ผูกรีวิวกับทริปใน TripBudget ได้ (อ่านรายชื่อทริปจากเครื่อง ไม่แก้ข้อมูล TripBudget)
- ค้นหา กรองตามประเภท และตามทริป
- ทั้งสองคนเห็นรีวิวชุดเดียวกัน แต่ละรีวิวบอกว่าใครจด ใครแก้ล่าสุด
- ติดตั้งเป็นแอปบน Android ได้ เปิดตอนสัญญาณไม่ดีก็ยังเห็นรีวิวที่โหลดไว้ล่าสุด

## ข้อมูลอยู่ที่ไหน

| ข้อมูล | ที่เก็บ |
|---|---|
| รีวิว | Google Sheet ของคุณ ชีต `Reviews` หนึ่งแถวต่อหนึ่งรีวิว |
| รูป | Google Drive โฟลเดอร์ `ที่นี่ดี รูป` |
| URL, รหัสเข้าแอป, ชื่อผู้ใช้ | ในมือถือแต่ละเครื่อง |

ไม่มีเซิร์ฟเวอร์อื่น ทุกอย่างอยู่ในบัญชี Google ของคุณ

## ตั้งค่าครั้งแรก (ทำครั้งเดียว ประมาณ 5 นาที)

ทำบนคอมจะง่ายกว่า

1. สร้าง Google Sheet ใหม่ ตั้งชื่อเช่น "ที่นี่ดี"
2. เมนู **ส่วนขยาย → Apps Script**
3. ลบโค้ดเดิม แล้ววางโค้ดทั้งหมดจากไฟล์ [`apps-script/Code.gs`](apps-script/Code.gs) กด 💾 บันทึก
4. ด้านบนเลือกฟังก์ชัน `setup` แล้วกด **เรียกใช้**
   - ครั้งแรกจะขอสิทธิ์ กด ตรวจสอบสิทธิ์ → เลือกบัญชี → ขั้นสูง → ไปที่โปรเจกต์ (ไม่ปลอดภัย) → อนุญาต
   - เตือนว่า "ไม่ปลอดภัย" เพราะเป็นสคริปต์ที่เราเขียนเอง ยังไม่ผ่านการตรวจของ Google
5. ดู **บันทึกการดำเนินการ** ด้านล่าง จะมีบรรทัด `รหัสเข้าแอป: xxxxxxxxxx` จดไว้
6. กด **ทำให้ใช้งานได้ → การทำให้ใช้งานได้รายการใหม่**
   - ประเภท: **เว็บแอป**
   - เรียกใช้ในฐานะ: **ฉัน**
   - ผู้ที่มีสิทธิ์เข้าถึง: **ทุกคน**
   - กดทำให้ใช้งานได้ แล้วคัดลอก **URL ที่ลงท้ายด้วย `/exec`**
7. เปิดแอป ใส่ชื่อ URL และรหัส แล้วกด "บันทึกและทดสอบการเชื่อมต่อ"
8. ส่ง URL กับรหัสให้แฟน ใส่ในมือถือของเขา (ชื่อใส่ของตัวเอง)

"ทุกคน" ในข้อ 6 หมายถึงทุกคนที่มี URL **และ** รหัสเข้าแอป ถึงจะอ่านหรือเขียนได้ คนที่ไม่มีรหัสจะถูกปฏิเสธ

## เรื่องที่ควรรู้

- **รูป** ถูกตั้งเป็น "ทุกคนที่มีลิงก์ดูได้" เพื่อให้แอปแสดงรูปได้ ลิงก์เป็นรหัสสุ่มยาว คนนอกเดาไม่ได้ แต่อย่าใส่รูปที่เป็นความลับ
- **รหัสหลุด** ให้เปิด Apps Script แล้วรันฟังก์ชัน `resetKey` จะได้รหัสใหม่ในบันทึกการดำเนินการ ใส่รหัสใหม่ในแอปทั้งสองเครื่อง
- **แก้โค้ด Code.gs** ต้องกด ทำให้ใช้งานได้ → จัดการการทำให้ใช้งานได้ → ✏️ แก้ไข → เวอร์ชัน: เวอร์ชันใหม่ → ทำให้ใช้งานได้ ถึงจะมีผล (URL เดิม)
- **ลบรีวิว** รูปของรีวิวนั้นจะถูกย้ายไปถังขยะของ Drive ส่วนแถวในชีตยังอยู่และขึ้นว่า "(ลบแล้ว)" กู้คืนได้ด้วยการแก้คอลัมน์ข้อมูลใน Sheet
- **ต้องมีเน็ตตอนบันทึก** ถ้าเน็ตหลุดระหว่างอัปโหลด รูปที่อัปแล้วจะไม่ต้องอัปซ้ำ กดบันทึกใหม่ได้เลย
- **TripBudget** ต้องเปิดด้วยเบราว์เซอร์เดียวกันบนเครื่องเดียวกัน ถึงจะเห็นรายชื่อทริป

## ไฟล์

| ไฟล์ | หน้าที่ |
|---|---|
| `index.html` | ตัวแอป |
| `apps-script/Code.gs` | โค้ดฝั่ง Google Sheet (วางใน Apps Script) |
| `sw.js` | ให้เปิดแอปได้ตอนสัญญาณไม่ดี |
| `manifest.json`, `icon*` | ข้อมูลสำหรับติดตั้งเป็นแอป |

แก้ไฟล์ไหนแล้ว ให้เปลี่ยนเลข `CACHE` ใน `sw.js` (เช่น `thineedee-v1.0.1`) เพื่อให้มือถือโหลดเวอร์ชันใหม่
