เชื่อมกับ Google Sheet ของคุณก่อนเริ่มใช้ ทำครั้งเดียว แล้วใส่ค่าเดียวกันในมือถือของแฟน ทั้งสองคนจะเห็นรีวิวชุดเดียวกัน

วิธีตั้งค่า Google Sheet (ทำครั้งเดียว)
  1. สร้าง Google Sheet ใหม่ ตั้งชื่อเช่น "ที่นี่ดี"
  2. เมนู ส่วนขยาย → Apps Script แล้ววางโค้ดจากไฟล์ apps-script/Code.gs ใน repo แทนของเดิม กดบันทึก
  3. เลือกฟังก์ชัน setup แล้วกด "เรียกใช้" อนุญาตสิทธิ์ จากนั้นดู "รหัสเข้าแอป" ในบันทึกการดำเนินการด้านล่าง
  4. กด "ทำให้ใช้งานได้" → "การทำให้ใช้งานได้รายการใหม่" → ประเภท "เว็บแอป" → เรียกใช้ในฐานะ "ฉัน" → ผู้ที่มีสิทธิ์เข้าถึง "ทุกคน" → คัดลอก URL ที่ลงท้าย /exec
  5. ใส่ URL และรหัสตรงนี้ แล้วส่งสองค่านี้ให้แฟนใส่ในมือถือของเขา

รหัสและ URL เก็บไว้ในเครื่องนี้เท่านั้น อย่าส่งให้คนอื่น ถ้าเผลอส่ง ให้รันฟังก์ชัน resetKey ใน Apps Script เพื่อเปลี่ยนรหัส
